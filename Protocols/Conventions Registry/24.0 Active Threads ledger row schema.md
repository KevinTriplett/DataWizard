# 24.0 Active Threads ledger row schema

**Rule:** every arc row is a `### T{N} - Name` block carrying exactly seven fields: `status / last / home / quest / next / docs / history`. `next:` holds **current state only, ~5 lines max**, written as the arc's **owed list**: one short line per item the arc still owes (what it waits on, a content leftover, a ruling, the single recommended next step), not a narrative of what the last session did. It points at the driver doc or its State Board for step state (link-don't-restate, applied to the ledger itself). Archaeology - "(Prior SNNN:)" chains, superseded next-steps, executed-plan detail - lives in the driver doc, the session log, or the Resolved archive, never in the row. `[SNNN note]` bullets are permitted as temporary carriers between closes; fold them into the canonical fields on the row's next substantive touch. `history:` stays a one-line session list. (DataWizard, 2026-08, 2026-10; D126)

**Example:** a dieted `next:` reads as an owed list, one sub-bullet per item: "G-003 (operator-native, ~15 min; unblocks the Reddit feeder)"; "the TG bridge build per the reviewed Step 1 design"; "step state: the driver doc State Board" - current state only; the prior plan's history lives in the session log.
